# svs

A Flutter library for displaying Aperio SVS (whole-slide image) files.

SVS is a pyramidal, tiled TIFF-based format commonly used to store
gigapixel whole-slide microscopy/pathology images. This package aims to
provide a Flutter widget and supporting APIs for reading and rendering
SVS files without loading the entire image into memory.
